# ATTRIBUTION

Every binary asset shipped in OpenMaps (icons, images, fonts, sounds, styles) needs a row here in
the **same commit** that adds the file. Original work: author = "OpenMaps (original)". Licensed
third-party: name the author, source URL, and licence.

| File | Author | Source | Licence | Notes |
|---|---|---|---|---|
| Material Icons font (bundled via `uses-material-design: true`) | Google / Flutter | https://github.com/google/material-design-icons | Apache-2.0 | Icon glyphs referenced through `Icons.*`. Permissively licensed; not Google Maps iconography. |
| Phosphor Icons font (bundled via `phosphor_icons: ^3.0.1`) | Phosphor Icons | https://github.com/phosphor-icons/phosphor-icons | MIT | Payment-method glyphs on the place sheet (`hand-coins`, `currency-btc`, `credit-card`, …). |
| `android/app/src/main/res/drawable/ic_nav_{drive,cycle,walk,transit}.xml` | Google / Material Icons | https://github.com/google/material-design-icons | Apache-2.0 | Travel-mode glyphs for the navigation notification and Android 16 status chip (`directions_car`/`directions_bike`/`directions_walk`/`directions_transit`), drawn in our own colour. Permissively licensed; not Google Maps iconography. |
| `test/features/goldens/*.png` | OpenMaps (original) | generated by `flutter test --update-goldens` | n/a | Test fixtures only — never shipped in the app. |
| `web/sqlite3.wasm` | SQLite (public domain); WebAssembly build shipped by drift | https://github.com/simolus3/drift (release `drift-2.34.4`) | Public domain (SQLite) · MIT (build) | drift's SQLite engine on the web; must be the same drift release as `web/drift_worker.js`. |
| `web/drift_worker.js` | drift (Simon Binder) | https://github.com/simolus3/drift (release `drift-2.34.4`) | MIT | Web worker drift uses to run SQLite off the main thread; same drift release as `web/sqlite3.wasm`. |

Rules (see `AGENTS.md` §Assets): nothing from Google Maps or any proprietary product; original,
public domain/CC0, OSI-open-source, or CC-with-redistribution only. Screenshots under
`plan/maps/screenshots/` are observation material and are **never** assets.

| Opening a place's contact details (dial / e-mail / website) | `url_launcher` (platform intents) | BSD-3-Clause / platform |
| Self-update (version check + APK install) | Owner-hosted HTTP manifest (`UPDATE_MANIFEST_URL`) + the Android package installer; `package_info_plus`, `crypto`, `path_provider` | BSD-3-Clause / platform APIs · no third-party service |
